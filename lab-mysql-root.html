Choix du port à cibler

MySQL écoute sur son port standard, accessible depuis le réseau.

rappel de la sortie nmap
3306/tcp open  mysql       MySQL 5.0.51a-3ubuntu5
indiceSur une installation durcie, MySQL n'écoute que sur localhost. Ici, le service est accessible depuis l'extérieur — un signal direct. à retenirLe compte root existe par défaut sur MySQL. La question n'est pas « comment l'exploiter » mais « qui peut s'y connecter ».
3

Connexion directe — sans mot de passe

kali@kali
$ mysql -u root -h 192.168.56.20 --skip-ssl
Welcome to the MySQL monitor.
Your MySQL connection id is 12
Server version: 5.0.51a-3ubuntu5 (Ubuntu)
mysql>
-u rootcompte d'administration par défaut MySQL — nom conventionnel, pas utilisateur système Linux. -h IPconnexion distante. Sans -p, le client ne demande pas de mot de passe. --skip-sslforce la connexion en clair. Nécessaire avec les vieilles versions MySQL. invitemysql> : on est dans un client SQL, pas un shell Unix.

Ce qu'il faut vraiment comprendre

« root » MySQL ≠ root système

Le compte root de MySQL est un utilisateur interne au SGBD. Il a tous les droits sur les bases, mais aucun droit sur le système d'exploitation.

Un compte sans mot de passe n'est pas une faille, c'est une absence de configuration

Pas de backdoor, pas de bug logiciel. MySQL a été installé, le compte root laissé sans mot de passe et en acceptant les connexions distantes. C'est une erreur de déploiement.

Ce que l'accès permet — et ce qu'il ne permet pas

On lit et modifie les données des bases. On peut aussi écrire des fichiers via INTO OUTFILE ou charger des UDF — techniques hors de ce cours.

Détection & remédiation

netstat -tulpn | grep 3306vérifier l'interface d'écoute (0.0.0.0 = exposé)
SELECT user, host FROM mysql.user;lister les comptes et leurs hôtes autorisés
bind-address = 127.0.0.1limiter à localhost dans my.cnf
SET PASSWORD FOR 'root'@'%' = PASSWORD('...');définir un mot de passe fort

Terminal d'entraînement

Rejoue la connexion et l'énumération. Le client SQL n'a pas les mêmes commandes qu'un shell Unix.

Ce qu'il faut vraiment comprendre

Backdoor ≠ vulnérabilité classique

Comme pour vsftpd, c'est une archive officielle modifiée après compromission du serveur de distribution. Pas d'exploit technique — juste un motif de message à envoyer.

Une commande magique comme déclencheur

UnrealIRCd 3.2.8.1 écoute les messages IRC. Toute commande préfixée par AB est interprétée comme une commande shell. Un simple message suffit.

Pas de meterpreter — un shell Unix brut

Le module utilise cmd/unix/reverse. On obtient directement un shell système, sans couche intermédiaire.

Anatomie de la backdoor

Comment du code malveillant s'est retrouvé dans l'archive officielle d'UnrealIRCd.

Une archive piégée sur le site officiel

Entre novembre 2009 et juin 2010, l'archive Unreal3.2.8.1.tar.gz proposée sur le site officiel a été remplacée par une version modifiée. Le numéro affiché restait 3.2.8.1.

Le déclencheur — commande préfixée « AB »

Tout message commençant par AB est interprété comme une commande shell, exécutée avec les privilèges du processus IRC (ici root).

reconstruction pédagogique — pas le code exact
// principe du contrôle ajouté au traitement des messages IRC
if (message starts with "AB") {
    execute_shell_command(message + 2);
}

Pourquoi ça change la méthode de recherche

Seule une vérification d'intégrité (hash SHA-1 ou MD5) aurait permis de détecter la compromission avant installation.

Détection & remédiation

sha1sum Unreal3.2.8.1.tar.gzcomparer le hash à celui publié par les mainteneurs
netstat / ss -tulpnsurveiller les connexions sortantes anormales depuis le serveur IRC
règle IDSsignature pour les messages IRC commençant par "AB"
ne pas tourner en rootlimiter l'impact si la backdoor est exploitée

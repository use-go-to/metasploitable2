Ce qu'il faut vraiment comprendre

Fonctionnalité légitime mal exposée ≠ backdoor

vsftpd et UnrealIRCd avaient du code malveillant injecté. distccd est un logiciel parfaitement légitime. Sa faille n'est pas dans son code mais dans sa configuration par défaut : accepter des requêtes de n'importe qui.

« Compilation distribuée sans authentification »

distcc envoie des tâches de compilation à un serveur distant pour accélérer les builds. Sans authentification, n'importe qui peut soumettre une « compilation » qui est en fait une commande arbitraire.

daemon n'est pas root

Le shell obtenu s'exécute sous UID 1 (daemon), pas root. Un accès utilisateur limité signifie qu'une étape d'élévation de privilèges sera nécessaire.

Détection & remédiation

ss -tulpn | grep 3632vérifier l'interface d'écoute (0.0.0.0 = exposé)
iptables / pare-feurestreindre l'accès à 127.0.0.1
--allow dans /etc/default/distccliste blanche d'adresses IP autorisées
systemctl stop distccddésactiver si non utilisé

Terminal d'entraînement

Rejoue la chaîne d'exploitation. Le cœur : vérifier le niveau d'accès réellement obtenu.
